# 时间轴、制作与质检

语言审校和机械检查分工明确。机器查漏项、重复、空译文、时间格式和固定轴约束；模型检查意思、阅读体验、画面遮挡。机器警告不是自动返工单。

## 三种粒度

ASR 音频块为识别工具服务；工作片段为专家理解服务；cue 为观众阅读服务。一个工作片段可以包含很多 cue。重制轴先整理完整语义，再按自然语音和译文分段；不把 160 毫秒识别片段原样交付。

fixed 模式保留源字幕条目、编号、顺序、时间。发现短闪或错轴，记录受限原因，不能偷偷修改。rebuild 模式可拆合：保留 parent_ids、文字对应关系、真实词/音节时间或回听定位。仅有句级时间时可以合并合适的相邻句，不能按字符数平均分配并声称精确拆分。没有可靠内部边界就保留较宽的语义组或明确等待对齐。

源稿初分条是显示初案。译文连贯成形后，译者或审校只标出需要拆合、重新分配文字的局部语义组，由制作员用已有词时间落实。词边界真实只说明可以在那里切，不说明适合在那里切：避免悬空的起句、被切开的限定关系和只剩泛指词的碎条；也不能把不同话题或动作仅因总时长不长就塞进同一条。结合目标语语序与发言进程决定边界，允许自然承接，保留对应关系，不为了凑一对一条数限制表达。

合并和改写时留意信息何时揭晓：对影响理解或戏剧节奏的转折、自我纠正、答案或包袱，避免把后一步认知提前塞进前一步字幕；同时避免把完整意思拖到已经转入下一动作之后。字幕按语义组显示，无需让每个译词逐词跟声。只在这些真实时序问题出现时检查对应短片或语音证据。基准参考轴不替代原片时序，也不能靠拉宽显示时间来增加评分重叠。

真实发声区间和显示区间分开。显示尾可在已检查的短停顿内适当延长；不能拖过下一发言、显著静默或场景变化。ASR 词尾不必等于显示尾。词时间只在源稿/制轴岗位处理，译者与语言审校无需逐字符复算。

字数少、阅读速度低和静态图清楚，都不能单独证明短条不会闪过。出现短闪风险时，先判断它是否承担独立反应、强调或节奏，再决定保留、合并或在已核实的停顿内延长；不要一律拉到固定时长。用已有收尾抽样检查有代表性的短片；不能动态观看时，说明哪些短条的观感尚未验证，不将静态渲染通过写成动态验收。

先忠实自然翻译，再控制显示长度。通常单语 1–2 行，双语上下各一行；游戏单语可按用户习惯采用一行。0.8–7 秒、每行约 21 个汉字、中文约 12 字/秒可作为初筛偏好，不能作为通用平台标准，也不能为了达标丢信息。重叠可能是多人同时说话；应选择样式、位置或合适排版表达，不能强制删掉真实发言以消除重叠。

制作时沿用[字幕呈现规则](language.md#字幕呈现)，检查逗号、句号是否已由空格或合理拆条承接。当前离线工具检查结构和阅读速度，不替代理判断标点功能；不能因机械检查通过就忽略字幕的观看风格。

## 一次有目的的收尾

1. 独立审校覆盖全段并完成保存稿连读。跨工作片段只检查边界衔接、人物称呼、关键术语及此前标记的跨章线索；不默认重译全片。
2. 制作员完成调轴/排版后，运行机械检查和导出。若只改显示时间、断行，语言结论保留；如果拆合引发文字重分配，审校专家只复查这个完整语义组。
3. 从实际交付文件渲染代表样本：开头、片段衔接、最密集文字、底部信息丰富画面和改过轴的困难片段。应真正查看渲染图；涉及短闪、动态遮挡、不同说话人或时序时看短片。制作员之外的人检查样本，可以仍是原审校专家。
4. 对样本发现的系统性问题先修制作规则，再检查受影响样本；明确局部问题只修局部。全片听看只在任务要求或实际风险支持时做，不能用静态图声称完成。

无视频的字幕任务跳过真实画面检查并注明。有视频而当前无法渲染/观看，则交付时保留相应限制。SRT 的位置由播放器决定；有特定遮挡要求时使用经实际检查的 ASS 样式或播放器设置。

导出后如再改字或改轴，应回写当前稿并重新导出受影响文件、更新检查。不要单独改交付 SRT，造成审校稿与成品不一致。

## 最小返工边界

| 变化 | 需要做什么 |
| --- | --- |
| 日志、文件移动、问题说明补全 | 更新项目记录；不重读字幕 |
| 标点或断行 | 检查格式/显示；不重做保真审校 |
| 显示时间改变、正文不变 | 检查局部轴和渲染 |
| 译文实质改变 | 核对该完整语义组；常规独立审校修订无需再起第三人审校 |
| 源文改字、否定/指代解释变化 | 更新对应译文和语义依赖的邻句；由另一位语言专家核对 |
| 译名或角色称呼改变 | 检索该词义/人物的出现处，修正有影响的条目 |
| 换音轨、换素材、时间基准变化 | 重新确认相关源稿与轴；不能沿用不匹配媒体的审定结论 |

最终说明包含成品路径、完成范围、重要未决项、音画实际审阅范围、工具限制。实质未决项未解决时标草稿，不在字幕里夹入内部审校长注。

## 基准复盘

仅在用户要求评测或比较时执行。先确认同一媒体、语言、参考文件及指标版本/参数，保存交付冻结状态与已知参考接触情况。版本比较按共同时间窗口或完整语义组对照实际字幕，不能把不同分段的第 N 条直接配对。

报告列出实际完成的各项指标、方向、输入版本和可比限制；未运行的指标明确留空，不把部分本地指标称为完整官方评测。以冻结导出文件为准，核对所用 JSON 确为其对应版本；案例附时间及成品编号。比较 ASR 后端时，将源稿识别差异与后续翻译、分段变化分开，不能把整条流水线的分差全部归因于识别后端。

先看指标定义和编辑分项，再对照源文、两版译文与参考，区分真实遗漏/误译、不必要扩写、合理异译、显示时序差异和参考自身的问题。SubER 的插入、删除、替换与移位是对齐操作，不是逐项语义错误判决；分条错误减少也不证明文字的时间归属全部正确。窗口总分差不能全算到其中某一句，文本长度差也不等于该删掉多少信息。

保留有依据的自然表达、术语和梗，不为贴近参考采用错误译法或丢掉真实内容。评分与案例可以支持一次通用规则修订，但单个已见样本不能证明新版本整体更好；不把参考答案写进生产词库，不反复改同片追分。用户只要求复盘或维护 skill 时，保持既有字幕和评测记录不变。
