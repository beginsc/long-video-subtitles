# 作者台词与音频重对齐（S11.5）

适用：已有作者/经校订字幕并取得原媒体，要制作新的观看版字幕。优先使用其台词内容，原时间、换行和标点只作定位或语义线索。仅提供字幕或用户指定保留轴时仍走 fixed。非自动轨不保证文本零错误；发现冲突单列疑点，不静默改写。

1. 保留字幕原件、轨道证据和文本摘要。将连续条目还原成语义句/段落，保留原 ID、字符/词跨度；不能逐条翻译残句后靠邻条猜补。不要把不同说话人、长停顿或无关背景台词混成一句。
2. 保留 WhisperX 音频处理：解码并核对媒体时间、运行明确记录的 VAD、将可信台词强制对齐到词。全文 ASR 可省略，注明 author-text + VAD + alignment；局部文本/时轴冲突时可用 large-v3 识别作证据对照，不能替换作者文本或默认引入 YouTube 自动字幕。
3. 对齐窗口可跨原字幕边界。原时间仅作为带前后余量的搜索种子，最终词时间不得裁回原 cue 起止。窗口按完整语义、VAD 与实际音频检查调整；过长则分块并核对衔接，避免重复词吸附到错误位置。原时间明显不准时扩大/重定位窗口，不能反复在错误裁片内强制匹配。VAD 不裁掉台词，也不保证排除歌声。
4. 检查未对齐词、零时长、异常长词、低分、顺序/重叠、窗口边缘聚集、与 VAD 明显冲突及时间偏移。分数只是筛查线索，不是正确率。异常局部重对齐或听校；不可对缺失时间按字数插值，不可将零缺词当成已听校。
5. 先按完整语义翻译，再按词级时刻、说话人、真实停顿及中文阅读节奏安排显示字幕。允许跨原条目合并和重新切分；不要留下孤立介词、连词、被切断的专名/数量单位或“它的／是因为”等空壳。长句允许多个自然意群，不能为凑12–18字切碎或漏义。否定、条件、对比、铺垫与后续反应需按出现顺序呈现。
6. 每条保留 parent_ids 及连续源文跨度，词时间和显示尾部延长分开记录；检查全片文本覆盖、重复遗漏、音乐空隙、短闪、CPS与长条。变更后重绑术语并重做受影响校对/编辑，按 semantic-preservation.md 做相邻窗口和改前后复核；抽查变化较大的拼接点并重新渲染。旧交付和 QA 保留，另存新版和对比报告。

台词可信、词级声学对齐、目标语言断句是三个不同判断。报告各自的依据与实际检查范围，不将作者字幕或 WhisperX 的分段自动称为最终时间轴。

数字、日期、缩写或混合语言可能有完整却过短的词时间。对实际异常，可另建只用于对齐的读音别名，保留原词/别名映射和候选；不要将展开后的文本覆盖作者台词。重新核对整个意群的开始与结束，分数仍不能代替必要的听校。
