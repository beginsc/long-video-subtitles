# 星际2实况解说词库

默认文件：`assets/glossaries/sc2/en-zh-CN.json`，版本 `2026-09-06.4`，风格 `commentary-zh-CN`。适合英译简中实况/比赛解说。共 328 条：人族 92、虫族 99、神族 89、通用 48；另有 394 个显式英文别名，包括常见复数和缩写。按单位、建筑、科技、技能、兵种组合、运营和战术分类，不宣称覆盖全部地图、选手、合作任务或自定义模式。

默认使用“人族/虫族/神族”和较常见解说名，例如枪兵、光头、火车、小狗、毒爆、火蟑螂、叉子、追猎、电兵。每个词义只有一个首选译名。正式解说、教学或剧情类视频如要求较正式名称，应在项目版本统一调整，不能在一部视频中随机切换。原来的四条官方名称起始库保留为 `en-zh-CN.official-starter.json`，它不是完整正式名称词库。

## 字段使用

除通用术语协议字段，SC2 条目还带：

- `faction`：对象的常见族别，用于阅读和筛选，不自动限制句子的族别。一条解说可能同时谈双方。
- `reference_target`：较正式名称参考。社区来源未独立核对官方中文时，不称为已验证官方名。
- `target_aliases`：中文俗称和快捷键参考；这些字段不会自动通过首选译名检查。切换译法应修改项目版本的 preferred_target。
- `usage_note`：歧义、动作/对象区分、译法限制。
- `era`：历史或版本敏感提示；按视频录制年代、游戏模式核对，不把历史条目删掉导致老录像漏识别。

英文可匹配别名只放在 aliases；中文参考别名不反向塞入英语规则。具体条目的 sources 保存逐条来源和检查日期。

2026-09-06.3 修正实测发现的共享昵称冲突：Photon Cannon 首选光子炮，Spine Crawler 首选地堡；不再把两种不同种族建筑默认译为同一词。旧任务的冻结词库不随之改变。

## 已处理的歧义与资料问题

| 情况 | 本库处理 |
|---|---|
| Worker 对应三族农民 | 单设通用农民条目；SCV、Drone、Probe 分别保存，不凭 Worker 推断族别。 |
| 英文 BC 与中文快捷键 BC | 英文 BC 作为 Battlecruiser 的语境别名；中文基地/光炮/地堡快捷键只作参考。 |
| VS、BE、BB 等快捷键跨族冲突 | 不当作英文源语别名；实际含义由族别和画面判断。VS 的“对阵”义不能变成建筑。 |
| Creep / Creep Tumor | 分别是菌毯与菌毯肿瘤，不合并成一个对象。 |
| Starport / Stargate / Spire | 分别为人族星港、神族星门、虫族龙塔。神族篇 Proxy Starport 不直接作为神族规范词。 |
| Gas | 资源“气”和具体采气建筑分开；实际计数表达需看句法。 |
| Float | 资源剩余与人族建筑升空分开解释，不能固定一个动词译法。 |
| Charge / Storm / Shade | 按升级、技能、动作或借指单位的实际语境解释；风暴战舰用 Tempest，避免混入灵能风暴。 |
| Nydus / Gate / Templar | 泛称保留语境要求；完整名称优先用于区分具体实体，不强行猜测缺失修饰词。 |
| All-in | 不等于必然拖农民；SCV Pull 单列。固定开局不自动补入文章举例的选手名、兵力和建造顺序。 |
| Corrusive / Statis / Phonenix / Mac Field | 规范为 Corrosive / Stasis / Phoenix / Mag-Field；错误拼写不自动当成正确源语别名。 |
| Glial Reconstruction | 规范为 Glial Reconstitution，保留名称核对来源。 |
| 母舰核心、电池超载和旧科技 | 保留历史条目并注明版本背景；不表示当前对战仍可使用。 |

`Sick`、`Funny`、`Cheeky`、`Greedy` 等感情色彩随语境变化，不设置“必译成某句粗口/贬义词”的固定规则；保留讲者原有语气，不从词典擅自增加辱骂。普通 move/stop、泛用名词也不为了增加词条数量全部设成强制规则。

## 在视频任务中使用

```text
python <skill>/scripts/glossary_workbench.py init terminology-library/sc2/en-zh-CN.v01.json --domain sc2
```

这会复制实况解说词库。其后仍按 [术语流程](terminology.md) 做全片发现、必要联网核验、逐次消歧和 bind；不是把词库直接用于全文查找替换。命中一个 require_context 条目，或 Creep/Creep Tumor 这类不同条目的重叠范围时，根据实际画面与句子记录 use/not_term；不把较短命中与较长名称分别重复翻译。

改动此库不会改变已有视频的冻结快照；需要在项目中显式加载新版本并重新 bind、校对和编辑。增加地图点位、选手外号或新的版本科技时另补项目证据，不把同名人物、另一款游戏或合作任务单位直接混入当前对战语境。


本轮维护版本 2026-09-06.4 增加 float-building（建筑升空/飞行搬迁），与资源剩余 float 保持同形多义并要求逐次消歧；不要通过将所有 float 统一为一种译法消除歧义提示。机制依据为[暴雪建筑升空指南](https://news.blizzard.com/en-us/article/5740266/game-guide-terran-lift-off)，中文为本库选择，不冒充该英文页提供了官方简中译名。旧任务继续使用已冻结词库，不自动更新。

2026-09-12.1 增加 Combat Shield（战斗盾牌，仅完整名称及复数，不把普通 shield 强制绑定为枪兵升级）及 Golden Wall（黄金墙，2020 年地图名）。来源记录区分地图实体与中文译名；同源转载不算独立确认。历史文章只用于名称，不据其旧数值解释当前版本。既有项目继续用冻结快照。
