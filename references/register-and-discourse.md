# 表达方式与段落功能（S11.3）

在翻译、校对和可选润色前，与 localization-and-naturalness.md 一起使用。领域决定词义和专名；表达方式决定语体、论证密度与修辞。两者独立判断。目标是保义且符合此类讲者的中文，不是把所有人改成同一种聊天口吻。

## 根据证据选语体

可参考的工作类型：即时解说、会话访谈、有组织的口头评论、讲授说明、作品/文献引用、混合或未知。观察实际源文及可用音画，不只看标题、频道或领域。电竞中的赛中反应、赛后复盘可能需要不同表达；评论中的分析、插话、作品引用也可能切换。同样不能由“播客”“脱口秀”等标签断言有没有稿。

“有组织的口头评论”描述可观察到的表达，不等于已确认作者使用台本。只有作者声明、用户提供稿件等证据才能把制作方式写成事实；其余记录判断依据与不确定性。中文参考和词汇重合度不能拿来推断英文讲者有无稿。

| 表达方式 | 应保留的功能 | 自然化的重点 |
|---|---|---|
| 即时解说 | 动作正在/即将/已经发生、反应顺序、现场猜测、自我纠正、有用重复 | 快速可读、对象明确；不提前揭示结果，不补成事后全知叙述 |
| 有组织的口头评论 | 论点、理由、例子、让步、比较标准、回扣、修辞意象 | 像向观众讲清一个判断；允许有层次的句子和专业概念，去掉翻译腔而非论证结构 |
| 会话访谈 | 接话、迟疑、确认、话轮关系、人物口吻 | 可用轻松中文，但不能删掉让交流成立的停顿或限定 |
| 讲授说明 | 定义、术语、步骤、因果条件 | 保持精度，以清楚的中文解释；不把技术表达当作书面腔 |
| 引用或刻意抒情段 | 引用归属、原有格调、意象关联、情绪落点 | 允许文艺或凝练表达；不得额外拔高，也不得改成平淡梗概 |

必要专业词可以嵌入简洁的口头句法；保留术语不等于增加“早已”“深谙……之道”等额外时间或格调。熟悉、贴切的成语也可以自然，不以四字形式或词表命中决定删除。

修辞是否保留，看它是否承担作用，而不是是否有四字词。只用于程度的习语可自然换说；承担分析、画面指向、连续意象或笑点回扣的修辞需保留关系。例如原文明说颜色/黑暗的反复对照，不能全部改成“人很复杂”；原文只有“很好”，也不能追加一串比喻。

## 接入现有项目配置

沿用现有九个字符串字段的 localization-profile.json，不新增 chinese_polish.prepare 不接受的顶层字段。用 register 写清本片主要表达方式和中文尺度，用 culture_policy 记录已有修辞/双关的保留边界。可从 [表达方式示例](../assets/register-profiles.json) 选择起点，根据源文调整；示例不是全领域强制默认值。

如同片存在明显切换，在项目另存 discourse-map.vNN.json，记录来源 ID 或真实时段、段落功能、语体变化、观察证据和未决事项。只在需要切换的连续批次准备相应九字段配置，并把必要邻文作为 readonly_context 传递；跨切换批次的 register 要明确各 ID 的边界，或沿真实连续 ID 边界拆批，不丢过渡句。

discourse-map 是项目编辑记录，不自动作为第十个字段传入 DeepSeek。现有脚本不会自行判型、读取此文件或强制模型遵守，执行者须实际读源文并把约定落到批次。将配置正文和摘要随项目保存；配置变化另存新版本、重建批次及其摘要，不能复用旧建议的审批摘要。

例：register 可以写“有组织的口头评论，面向熟悉动画的普通观众；自然但不刻意碎句，保留论点—例证—转折以及原有的情绪总结；插话可轻松，不能抹去作品引用的原有语体”。这种项目语体信息经已批准提示词的 project_profile 输入；不擅自更改获批的系统提示词。

## 初译、润色与编辑复核

1. 先确定本段在做什么：反应、叙事、分析、让步、反讽、总结、引用，允许并存。没有证据就保守保留现有语体，不凭句子长推定文艺腔。
2. 区分三类问题：源文原有的复杂意思；原文有意使用的修辞；翻译额外制造的复杂句法。优先处理第三类，前两类先保功能再说顺。
3. 连读完整中文语义组，检查评价依据、论证转折和回扣仍能接上。不能因为“更像说话”而删成只有结论，也不能把让步/反讽改成直白赞同或客观定论。
4. 对同样准确的自然版本，没有必要仅因另一个更短就改。将“更精炼”“更生活化”作为有条件的偏好，而非逐句改写任务。
5. 复核语气强度与形象本身：强烈肯定不能弱化成“说得清楚”；画面里的象征变化不能随意替换为译者对其意义的解释。这些是保真问题，不得用风格偏好免责。
6. 技术排版与语体分别处理：主交付仍为用户要求的单语单行；长句先检查实际阅读速度、词边界和可用时间。仅在获授权重制轴时重分段，固定轴则保留必要内容并记录超限。单行不意味着一句论证必须砍成十几个字。

DeepSeek 继续只提供必要建议，GPT 复核。允许保留原文个性不等于邀请模型写得更文学；增加吐槽或套用某位中文创作者的口癖也不是本地化要求。中文风格参考只帮助确定目标语可接受的表达范围，不提供待译事实、不复制参考台词、不作为质量绝对标准。

## 评估记录

将保真、中文自然度、原作者语体一致、论证/修辞功能、字幕可读性分开观察。用户认为更像人说话可记录为用户定性反馈，不能直接换算成正确率或模型单独收益。机器分数仍按既定流程完整报告；参考措辞不同可能与语体有关，也可能来自内容、对齐或译法错误，不预设全部原因。

比较完整上下文中的候选与参考，单列：内容错误、可接受异译、语体取舍、原声疑点、参考差异及对齐截断。分数下降不等于应该回到书面腔，语句更顺也不能证明含义更准。若研究 DeepSeek 的净收益，保持 ASR、源稿、GPT编辑规则、标点、排版和指标配置一致，只改变是否加入润色建议；新版本冻结后再评分，不覆盖既有结果。
