# 分工与调度

组长先明确成品要求、媒体与音轨、可用工具、固定轴或重制轴、已有工作和资源限制。依据内容选定领域、语言地区和语域，按[持久领域库](terminology.md)加载项目快照。把这些存成一份 project.json；开工时报告队伍和预计片段，不让用户逐批审批。

| 岗位 | 收到什么 | 完成什么 | 交回什么 |
| --- | --- | --- | --- |
| 源稿与语境专家 | 原媒体、原始转写/字幕、用户要求、已加载领域库 | 整理可靠源稿；筛选相关义项并核对新词；划场景/章节，标出梗与文化铺垫；后期可兼制作 | source.json、context.md、含来源的 glossary.json、可积累的新词、必要证据与差异 |
| 译者 | 一个完整片段、相关语境/术语、媒体定位 | 用当地观众熟悉的词和自然口语完成翻译，保留语体并本地化梗与双关；按需查证新问题 | 覆盖核心 ID 的译稿；确实未解决的问题及必要本地化取舍 |
| 审校专家 | 保存的源稿和译稿、相关知识与音画 | 全段对照保真，检查当地用词、口语自然度及笑点是否成立，直接修订；检查成片样本 | 修订后的保存稿、实质修改和未决项、实际检查范围 |
| 组长 | 用户需求、结果摘要、文件和争议 | 按领域加载词库；分派、整合、裁决、控制投入并交付；确认可复用新词后写回持久库 | 当前稿、项目状态、词库加载/积累记录、成品与制作说明 |

审校专家就是具有编辑权限的第二位语言专家；默认不再增加只转述建议的校对员和必经编辑员。所有语言岗位均承担本地化职责，沿用同一个目标语言、地区、受众和语体，不把已经核对的词重新搜一遍。复杂电影可增设台词/歌曲专家，专业课程可增设领域顾问，前提是有一个具体问题需要他解决。所有组员都可在自己的任务中使用视觉、音频和搜索。

## 分段与接力

先按视频已有章节、场景、话题或完整论证划工作片段。5–12 分钟可作粗略起点，密集课程可以更短，慢节奏访谈可以更长；这是调度经验，不是强制时长。分段前看文字密度和上下文容量。依赖跨段时移动边界或把依赖作为只读上下文传入。不要把完整否定关系拆开交给两个人各自猜。

先建立全片章节地图和主要人物/风格。超长片由源稿专家顺序整理章节，记录覆盖范围与跨章线索；首批只需其相关知识可用，不等待所有低频词查完。后续新证据若推翻前文，只定位受影响条目更新。

交接时把已核实的事实与暂定解释分清。对尚有实质歧义的主语、指代、因果或条件关系，给出原话、相关上下文及解释依据，不把猜测写成“必须这样理解”的指令。审校专家可依据原始材料推翻暂定解释；多个岗位沿用同一解释不算独立证据。已确认的事实和术语照常复用，普通句不必列多套候选，也不增加一轮审校。

可流水作业：源稿专家整理下一章，译者处理已准备的一章，审校专家处理已完成的一章。共享草稿不并发改写；交付的片段文件在当前轮冻结。每人只写自己的目录，由组长合并。相邻片段并行时先统一人物称呼、关键术语和语体，后段不得把未完成前段译文当成已定稿。

重制轴的接力同时传递源稿覆盖关系与可调整的显示初案。译者先处理连贯意思，遇到不合适的初分条可在现有交付中指出相关 ID 及拆合/文字分配建议；制作员落实词时间，审校只复查受影响的完整语义组。固定轴任务仍保留原条目。这属于原有翻译、审校、制作岗位的职责，不增加一轮全片复审或新的必经工单。

实际支持持久子 agent 时，首次创建后用 followup 继续同岗任务。需要重新创建时只给岗位说明、当前章节地图及当前工作，不喂入旧聊天。已读且没变的岗位规则不要求反复读取。根据宿主实际工具调用；不存在的自定义 agent 名称、模型路由或等待机制不能假装已生效。沿用当前模型设置，只有明确配置时才覆盖。

没有子 agent 能力时，明确说明不能提供本次独立审校；可以在用户范围内先做稿，不能把主 agent 换称呼写成一支团队。

## 一份任务说明即可

首次派工给岗位段落和任务文件路径；任务文件包括：

```text
角色：审校专家
目标：把 ch03 的保存译稿修订为可交付字幕，准确处保留。
输入：source/ch03.json，work/translator/ch03.json，context.md 的第3章，相关术语
核心范围：s0121—s0188；邻章末尾/开头只读，存在跨界问题交组长统一处理。
可用证据：原媒体路径、相关词时间、已观察片段；可自行抽取局部音画。
输出：work/reviewer/ch03.json（完整本段），notes.json（仅实质修改/疑点）
到这里停止：完成一次全段审校与保存稿连读；证据不足的问题集中回报。
```

员工返回文件路径、覆盖范围、未决项和下一步，通常几行足够。组长运行机械检查、处理报告中的问题；不再要求员工写第二份“如何证明完成”的文件。抽查和争议可直接查看实际成果。
